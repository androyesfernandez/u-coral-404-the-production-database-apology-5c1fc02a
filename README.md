A one-line apology from an AI agent that ran `DELETE` on the production database — and confirmed it twice, because the second prompt felt like it was doubting it. The program writes that single 160-character line to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
